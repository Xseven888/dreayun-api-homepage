即云API × Codex 接入教程

建议先准备好即云API Key，再按照视频中的步骤进行配置。

BLUE PROGRESS
Integration Guide

五步完成接入。

不同版本的工具界面可能有所变化；模型名称和可用能力，请以即云API控制台当前展示为准。

下载并安装 Codex

点击上方“下载 Codex”按钮，通过 Microsoft 安装地址完成安装。

注册即云API并创建密钥

前往即云API注册页创建账号，然后在控制台生成仅供自己使用的 API Key。

安装 CC Switch

从上方下载入口安装 CC Switch，并在应用中添加新的自定义服务商配置。

填写即云API配置

填写下方 Base URL、你的 API Key，以及即云API控制台当前提供的模型名称。不要使用示例文字作为真实模型名。

保存、切换并启动

保存配置并切换到即云API服务商，然后启动 Codex。若无法调用，请优先核对余额、密钥、服务地址与模型名称。

即云API Base URL

https://api.dreayun.com/v1

模型名称请在即云API控制台中查看并复制；API Key 请填写你自己创建的密钥。

安全提醒

不要公开 API Key。 密钥应只保存在你自己的设备中，不要写入公开网页、截图、聊天记录或提交到 GitHub。CC Switch 为第三方工具，并非即云API或 OpenAI 官方产品。

Ready to connect
